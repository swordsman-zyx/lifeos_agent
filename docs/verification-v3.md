## 真实模型与网页

使用本地已有模型配置，独立测试数据库 `.test-output/ui-preview-lifeos-v3.sqlite3`，独立端口 18000 / 18001。未修改真实 key，未将测试偏好或订单写入默认业务数据库。

实际完成：

1. LifeOS 路由到 Memory，保存“饮品偏好无糖”。
2. 新会话查询并读回同一长期偏好。
3. LifeOS 路由到 Food，查询 MCP 并创建麦当劳 1+1 购物车。
4. 会话内展开规格、费用、地址及偏好来源。
5. 人工确认后从顶层恢复，模拟支付成功，左侧出现最近订单。
6. 点击最近订单展示只读详情，不出现再次提交按钮。
7. 刷新页面后恢复消息及订单卡片。

第一次 Memory 调用遇到模型连接错误，页面明确提示未更新，没有假装保存成功；随后重试成功。真实联调不能代表所有自然语言输入都具有相同效果，仍依赖模型服务和网络可用性。
